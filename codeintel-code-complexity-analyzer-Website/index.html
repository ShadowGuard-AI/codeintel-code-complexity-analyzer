codeintel-code-complexity-analyzer

The Sizing Line. A command line analyzer that passes one Python file over radon's sizing rings and reports only the blocks whose cyclomatic complexity scores strictly above its threshold.

The repository main.py
One file at a timeA single positional filepath; there is no directory mode
The ring size--threshold defaults to 10 and filters strictly: a block exactly on it is not listed
True line numbersThe original text goes to radon's visitor as read, so spans are true source lines
Raw metrics--report-raw adds radon's raw metrics from a second read of the file

Usage

python3 main.py FILE [--threshold N] [--report-raw]

Only what passes the ring is reported: each block scoring above the threshold prints with its line span and a warning. When nothing exceeds it, the run prints one plain line saying so.

OptionWhat it does
filepathThe one Python file to score. A file that cannot be read or parsed exits 1.
--thresholdThe ring size, default 10. Only blocks scoring strictly above it print. A threshold of zero or below exits 1.
--report-rawThe README parameter list gives this flag No description provided; the help text in main.py describes it in full. It adds radon raw metrics: source lines, logical lines, comments, multi line strings, blank lines, and single comments.

What the rings pass

  • A quiet run means no block scored above the threshold. It does not mean the file is simple at every size: lower the ring and more is caught.
  • The GitHub description claims the tool uses the ast module. The code imports radon and uses no ast anywhere; the README records the mismatch and this site repeats only what the code does.

Requirements

Python, plus radon 6.0.1 or later.
