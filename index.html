One File Text

codeintel-code-complexity-analyzer calculates cyclomatic complexity and other code complexity metrics for Python code.

The Original Text Is Passed On

The original file text is passed to the radon library for calculation, whereby reported line numbers remain true source line numbers. Only functions or classes exceeding the defined complexity threshold are reported, and a plain line is printed when no block exceeds it.

True Line Numbers

Reported line numbers are true source line numbers, because the original file text is what radon receives.

Three Parameters Only

-hShows the help message and exits.
--thresholdGives the complexity threshold for reporting functions and classes, and defaults to 10.
--report-rawNo description provided.

Over the Threshold and Reported

Blocks reported are functions or classes whose complexity exceeds the threshold, identified alongside their true source line numbers. A run uncovering no block beyond the threshold prints a plain line stating so. No sample output, no invented function names, and no threshold table beyond the single default of 10 appears here, because the README provides none.
